# anvugia.io

Marketing site for **An Vu Gia Ltd** — IT services, AI consulting and
investment tooling.

Hand-written static HTML, CSS and JavaScript. No framework, no package
manager, no build step: what is in this repository is exactly what GitHub Pages
serves.

---

## 1. What is in here

```
index.html                  the whole site — one long landing page
404.html                    themed not-found page (GitHub Pages serves it automatically)
CNAME                       contains "anvugia.io" — tells Pages the custom domain
.nojekyll                   stops GitHub Pages from running Jekyll over the files
robots.txt                  crawl rules + sitemap pointer
sitemap.xml                 one URL, updated by hand when content changes
assets/
  css/style.css             the entire design system, commented in sections
  js/main.js                progressive enhancement only (see §6)
  img/favicon.svg           the ✳ mark
  img/og-cover.jpg          1200×630 social share card (progressive JPEG)
tools/
  gen-series.js             regenerates the illustrative chart data
  make-og.py                regenerates og-cover.jpg
design-ref/                 LOCAL ONLY — git-ignored, never published (see §7)
```

Page sections, in order: hero → statement → three practices → process (dark) →
investment tools → integrations → capability metrics → contact → footer.

## 2. Preview it locally

Any static file server works. From this directory:

```powershell
python -m http.server 8080
# then open http://127.0.0.1:8080/
```

Opening `index.html` directly from the filesystem also works, but a server
matches how GitHub Pages serves the files (correct MIME types for the SVG and
the JS module-less script).

## 3. Publish to GitHub Pages

The remote is already configured: `git@github.com:tariusagi/anvugia-io.git`.

```powershell
git add -A
git commit -m "Add An Vu Gia Ltd site"
git push -u origin main
```

Then in the repository on GitHub:

1. **Settings → Pages**
2. **Source:** `Deploy from a branch`
3. **Branch:** `main` · **Folder:** `/ (root)` → **Save**

Leave **Custom domain** empty for now; the `CNAME` file in the repository sets
it, and GitHub will fill the field in on the first successful build. Tick
**Enforce HTTPS** once the certificate has been issued (usually a few minutes
after DNS resolves).

There is no GitHub Actions workflow on purpose — for a purely static site the
branch deploy is one less thing to break. If you later want build steps, switch
**Source** to `GitHub Actions` and add a workflow at that point.

### DNS for anvugia.io

At your DNS provider, for the apex domain `anvugia.io`:

| Type  | Name | Value |
| ----- | ---- | ----- |
| A     | `@`  | `185.199.108.153` |
| A     | `@`  | `185.199.109.153` |
| A     | `@`  | `185.199.110.153` |
| A     | `@`  | `185.199.111.153` |
| CNAME | `www` | `tariusagi.github.io` |

Then point `www` at the apex with a redirect rule at your DNS provider, or
simply use the apex. Do not create a wildcard record — it breaks the HTTPS
certificate.

Verify with `nslookup anvugia.io` and, once Pages reports the domain as
verified, tick **Enforce HTTPS**.

## 5. The chart is illustrative — keep it that way

The equity curve in the *Investment tooling* section is **synthetic sample
data**, generated by `tools/gen-series.js` with a fixed random seed. It is not
a real backtest and not a performance record. The panel is labelled
`sample data`, and the section carries a "not investment advice" notice.

If you replace it with real numbers:

- regenerate both the SVG path and the `SERIES` array together (§6), and
- keep a disclaimer — the current one is a reasonable starting point for a
  software-and-tools business that does not manage money.

## 6. Editing notes

**`assets/js/main.js` is enhancement only.** With JavaScript disabled the page
renders fully: the terminal lines are visible, the orbit ring is drawn, the
chart shows its final value, and every link works. The script adds:

- sticky-nav state and the active section tab,
- reveal-on-scroll animations (skipped entirely under `prefers-reduced-motion`),
- the chart crosshair readout — pointer **and** keyboard
  (`←`/`→` step, `Shift` + arrow jumps 10 days, `Home`/`End` jump to the ends).

**Regenerating the chart data.** After editing `tools/gen-series.js`:

```powershell
node tools/gen-series.js
```

Paste the two printed `path d` strings into the two `<path>` elements in
`index.html` (the stroke one and the area-fill one), then paste the printed
`SERIES` and `GEO` lines into `assets/js/main.js`. The generator prints both so
the drawing and the readout can never disagree. Maximum drawdown is derived in
JavaScript from `SERIES`, so it updates itself.

**Regenerating the share card.**

```powershell
python tools/make-og.py
```

It downloads Instrument Serif and JetBrains Mono into a temp directory (they
are not committed) and rewrites `assets/img/og-cover.jpg`. The palette
constants at the top of the script match the CSS tokens.

**Design tokens** all live at the top of `assets/css/style.css` — the paper and
navy surfaces, the ink ramp, the CRT-blue accent, the hairline opacities, the
three font stacks and the motion easing. Change them there rather than
scattered through the file.

**Fonts** are loaded from Google Fonts (Instrument Serif for display, Inter for
body, JetBrains Mono for labels and data). To self-host them instead, download
the three families, add `@font-face` rules, and drop the `<link>` tags — the
CSS already falls back to Georgia, the system UI font and the platform mono
font, so the page never depends on the CDN to be readable.

## 7. `design-ref/` is not part of the site

That folder holds the Dribbble screenshots used as a visual reference while
building. They are other designers' work, so they are listed in `.gitignore`
and will never be committed or published. Keep them local, or delete the folder
when you no longer need it.

## 8. Browser support and accessibility

Targets current Chrome, Edge, Firefox and Safari, plus iOS and Android Safari.
Older browsers lose the frosted nav and the reveal animations but keep the full
content and layout — nothing is hidden behind a modern-only feature.

- One `<h1>`, ordered heading levels, `main`/`header`/`footer`/`nav` landmarks
  and a skip link.
- The decorative monitor, orbit and dome diagrams are exposed as single
  labelled images, not as dozens of meaningless nodes.
- The chart is focusable and scrubbable from the keyboard, and its readout is
  an `aria-live` region.
- Focus rings are visible on every interactive element.
- All motion collapses under `prefers-reduced-motion: reduce`.
- Contrast was measured against the actual surface colours. Functional
  secondary text is `--ink-soft` (#556772) at 5.0:1 on paper; accent-coloured
  text uses `--accent-ink` (#2c5f88) at 5.8:1; muted text on navy is 7.1:1.
  The faint tone (`--ink-faint`) is reserved for decorative marks — the
  parenthesis glyphs and the ◆ superscript — and is never used for copy.
